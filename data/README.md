## Reproducing the data from scratch

All runs use `mrefin=6` (97×97 grid), default physical parameters, and
start from the equilibrium state generated by the spin-up run.

### 1. Spin-up (generates the equilibrium initial condition)

```bash
python qg_model.py \
    --mrefin 6 --tend 100000 --dt 1 --dtout 40 \
    --scheme rk4 --ic fourier --seed 42 \
    --out qg_spinup.npz
```

Runtime: ~10 min on a modern laptop.
The last record (`t=100000`) is used as restart for all subsequent runs.

### 2. Reference RK4 run

```bash
python qg_model.py \
    --mrefin 6 --tend 110000 --dt 1 --dtout 40 \
    --scheme rk4 --ic restart --restart-file qg_spinup.npz \
    --out qg_rk4_ref.npz
```

### 3. Leapfrog runs — RA filter, varying alpha

```bash
for ALPHA in 0.05 0.10 0.15 0.20; do
    python qg_model.py \
        --mrefin 6 --tend 110000 --dt 1 --dtout 40 \
        --scheme leapfrog --ra-alpha $ALPHA \
        --ic restart --restart-file qg_spinup.npz \
        --out qg_lf_ra_a${ALPHA}.npz
done
```

### 4. Leapfrog runs — RAW filter

```bash
python qg_model.py \
    --mrefin 6 --tend 110000 --dt 1 --dtout 40 \
    --scheme leapfrog --ra-alpha 0.1 --raw \
    --ic restart --restart-file qg_spinup.npz \
    --out qg_lf_raw.npz
```

### 5. Stability sweep — varying dt

```bash
for DT in 0.5 1.0 2.0 3.0 4.0; do
    python qg_model.py \
        --mrefin 6 --tend 110000 --dt $DT --dtout 40 \
        --scheme leapfrog --ra-alpha 0.1 \
        --ic restart --restart-file qg_spinup.npz \
        --out qg_lf_dt${DT}.npz
done
```

### 6. Resolution sweep — varying mrefin

```bash
for MREFIN in 5 6 7; do
    python qg_model.py \
        --mrefin $MREFIN --tend 110000 --dt 1 --dtout 40 \
        --scheme leapfrog --ra-alpha 0.1 \
        --ic fourier --seed 42 \
        --out qg_lf_mrefin${MREFIN}.npz
done
```

Note: `mrefin=7` (193×193 grid) requires ~1 hour and ~4 GB RAM.

## File naming convention

| File | Description |
|------|-------------|
| `qg_spinup.npz` | Spin-up run — equilibrium IC source |
| `qg_rk4_ref.npz` | RK4 reference (Section 3) |
| `qg_lf_ra_a0.10.npz` | Leapfrog + RA, alpha=0.10 |
| `qg_lf_raw.npz` | Leapfrog + RAW, alpha=0.10 |
| `qg_lf_dt{X}.npz` | Leapfrog + RA, dt=X (stability sweep) |
| `qg_lf_mrefin{X}.npz` | Leapfrog + RA, mrefin=X (resolution sweep) |
